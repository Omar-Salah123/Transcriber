# Local runtime data

This directory is reserved for uploaded images, SQLite records, extraction output,
and generated workbooks. The placeholder app does not create any runtime data.

Everything under this directory except this README is ignored by Git. Keep client
files here when the storage feature is implemented, not in source or test folders.
Use your organization's approved backup process for local client data; Git does
not back it up. Avoid deleting this directory when cleaning development artifacts.
